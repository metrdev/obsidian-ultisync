# Установка и завершение перехода

Сборка 1.1.0 подготовлена для проверки. Автоматические тесты и тестовый GitHub-обмен не подтверждают работу на настоящем iPhone.

## На каждом устройстве

1. Обновить Obsidian до версии не ниже 1.13.0.
2. Поместить `main.js`, `manifest.json`, `styles.css` в `.obsidian/plugins/personal-vault-sync` внутри vault. На iPhone дождаться доставки файлов через iCloud.
3. Открыть **Settings → Community plugins** и включить **Personal Vault Sync**.
4. Создать отдельный fine-grained GitHub token: только `metrdev/personal-notes`, **Contents: Read and write**. Ввести его непосредственно в плагине на каждом устройстве. Не присылать токен в чат. Существующий доступ настольного Git к полному бэкапу остаётся отдельным.
5. Проверить `metrdev`, `personal-notes`, `main`, нажать **Save**. При первом сравнении просмотреть список. Ожидаются шесть файлов; обе стороны должны совпадать. Не выбирать очистку или перезапись при неожиданном различии.
6. Проверить время последнего успешного pull/push и отсутствие ошибок. Если SecretStorage или IndexedDB недоступны, обмен останется выключенным.

## Доступ обычного ChatGPT

Открыть GitHub **Settings → Applications → Installed GitHub Apps → Configure** для подключения обычного ChatGPT. Выбрать **Only select repositories**: `prompts` и `personal-notes`. `ObsidianGeneralNotes` этому подключению не предоставлять. Другие рабочие подключения не изменять.

Проверить из нового обычного чата чтение полного актуального документа `personal-notes`, затем безопасную правку с предварительной проверкой SHA. Проверка доступа из Codex не доказывает права другого подключения ChatGPT. Настройка подключения сама по себе не гарантирует свежесть чтения.

## Приёмка и бэкап

Пройти [ACCEPTANCE.md](ACCEPTANCE.md), особенно проверку телефона при выключенном ПК и последующего запуска SyncGuard. До подтверждения оставлять новый автоматический бэкап выключенным; старый `obsidian-git` пока сохраняется.

Для полного переключения после проверки бэкапа и восстановления: отключить `obsidian-git` в Community plugins, затем включить **Daily backup on this computer** у Personal Vault Sync. Этот переключатель не переносится на телефон.

## Откат

Сначала сохранить новые версии с телефона и GitHub отдельно. Отключить новый плагин. Сравнить и восстановить затронутые файлы, прежнюю конфигурацию SyncGuard, симлинки и настройки старого бэкапа из локальной копии миграции. Не включать старую пару `preferences`, пока файлы в старом источнике не согласованы: теперь там указатели, а не исходные заметки.

Историю репозиториев не переписывать. Полную резервную копию восстанавливать в отдельную папку.
